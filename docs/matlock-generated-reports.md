# Matlock Generated Report Templates

**Version:** 0.1.x

This document specifies the four Jinja2 Markdown dashboard types generated by the `report` stage. All output files are written to `output_directory` (`_Matlock/` by default) and render natively in Obsidian, VS Code, and GitHub without plugins.

Template files live at `matlock/templates/`.

---

## 1. Global Dashboard

**Template:** `matlock/templates/daily_dashboard.md.j2`
**Output:** `_Matlock/Home.md`
**Regenerated:** On every `matlock report` or `run-all` call; automatically by server mode after the nightly `rollup`.

### Template

```jinja
# ☀️ Good Morning: Matlock Daily Dashboard
**Date Generated:** {{ generated_at }}

## 🔥 Momentum & Streaks
* **Current Streak:** {{ current_streak }} Days
* **Longest Streak:** {{ longest_streak }} Days{% if longest_streak_end %} (Ended: {{ longest_streak_end }}){% endif %}

## 🟩 Activity Heatmap (Last 5 Weeks)
*Daily Tasks Completed: ( ⬜ 0 | 🟩 1–3 | 🟦 4–7 | 🟪 8+ )*

| | W-4 | W-3 | W-2 | W-1 | Current |
|---|:---:|:---:|:---:|:---:|:---:|
{% for day in ["Mon","Tue","Wed","Thu","Fri","Sat","Sun"] -%}
| **{{ day }}** | {{ heatmap[day][-5] }} | {{ heatmap[day][-4] }} | {{ heatmap[day][-3] }} | {{ heatmap[day][-2] }} | {{ heatmap[day][-1] }} |
{% endfor %}
## 🏆 Yesterday's Wins
*You completed **{{ yesterday_completed_count }} tasks**. View full details: [[{{ yesterday_date }}]]*
{% for project_id, count in yesterday_by_project.items() %}
- **[[{{ project_id }}]]**: {{ count }} tasks completed
{%- endfor %}

## 🎯 Today's Focus

### ⏰ Past Due
{% if past_due_tasks %}
{% for task in past_due_tasks %}
- [ ] {{ task.task_text }} *(Due: {{ task.due_date }})* 🔗 [[{{ task.file_path | basename }}]]
{%- endfor %}
{% else %}
*Nothing past due. Keep it up!*
{% endif %}

### 📅 Due Today
{% if due_today_tasks %}
{% for task in due_today_tasks %}
- [ ] {{ task.task_text }} 🔗 [[{{ task.file_path | basename }}]]
{%- endfor %}
{% else %}
*No tasks due today.*
{% endif %}

### 📊 Task Matrix By Priority
| View | ⏫ High | 🔼 Medium | 🔽 Low | None |
|:-----|:-------:|:---------:|:------:|:----:|
{% for row in task_view_table_rows %}
| [{{ row.label }}]({{ row.view_link }}) | {% if row.cells[0].link %}[{{ row.cells[0].display }}]({{ row.cells[0].link }}){% else %}-{% endif %} | {% if row.cells[1].link %}[{{ row.cells[1].display }}]({{ row.cells[1].link }}){% else %}-{% endif %} | {% if row.cells[2].link %}[{{ row.cells[2].display }}]({{ row.cells[2].link }}){% else %}-{% endif %} | {% if row.cells[3].link %}[{{ row.cells[3].display }}]({{ row.cells[3].link }}){% else %}-{% endif %} |
{% endfor %}

## 🕒 Recently Changed Files
{% if recently_changed_files %}
{% for file in recently_changed_files %}
- **{{ file.changed_at_text }}** - [{{ file.file_path | basename }}]({{ source_link(file.file_path) }})
{% endfor %}
{% else %}
*No tracked files found.*
{% endif %}

## 🧭 Active Projects Hub
{% for sp in super_projects %}
- 🌍 [[{{ sp.id }}]] — {{ sp.title }}
{% endfor %}
{% for p in projects %}
- 🚀 [[{{ p.id }}]] — {{ p.title }}
{% endfor %}
```

### Template Variables

| Variable | Type | Source |
|:---------|:-----|:-------|
| `generated_at` | str (YYYY-MM-DD HH:MM) | Runtime |
| `current_streak` | int | Calculated from `daily_metric` |
| `longest_streak` | int | Calculated from `daily_metric` |
| `longest_streak_end` | str \| None | YYYY-MM-DD |
| `heatmap` | dict[str, list[str]] | Day-name → list of emoji per week (5 entries) |
| `yesterday_completed_count` | int | `daily_metric` |
| `yesterday_date` | str | YYYY-MM-DD |
| `yesterday_by_project` | dict[str, int] | `daily_metric` |
| `past_due_tasks` | list[Task] | `task` table query |
| `due_today_tasks` | list[Task] | `task` table query |
| `task_view_table_rows` | list[object] | Dashboard matrix rows grouped by due view and priority tier; populated cells link to page anchors (`#priority-high`, `#priority-medium`, `#priority-low`, `#priority-none`) |
| `recently_changed_files` | list[object] | Top changed non-generated files from `file` table (limited by `dashboard_recent_changes_limit`) |
| `super_projects` | list[SuperProject] | `super_project` table |
| `projects` | list[Project] | `project` table |

### Heatmap Emoji Scale

| Emoji | Completed tasks |
|:------|:----------------|
| ⬜    | 0               |
| 🟩    | 1–3             |
| 🟦    | 4–7             |
| 🟪    | 8+              |

## 2. Project Page

**Template:** `matlock/templates/project.md.j2`
**Output:** `_Matlock/Projects/<project_id>.md`
**Regenerated:** Per-project when affected files change (server mode) or on `matlock report`.

### Template

```jinja
# 🚀 Project: {{ project.title }}

**Priority:** {{ project.priority | title }} | **Start Date:** {{ project.start_date or "—" }} | **Due Date:** {{ project.due_date or "—" }}
{% if project.super_project_id %}**Super-Project:** [[{{ project.super_project_id }}]]{% endif %}

## 📊 Quick Stats
| Metric | Count | Estimated Effort |
| :--- | :--- | :--- |
| **Open Tasks** | {{ stats.open_count }} | {{ stats.open_minutes }} mins |
| **Completed** | {{ stats.completed_count }} | {{ stats.completed_minutes }} mins |
| **Past Due** | {{ stats.past_due_count }} | {{ stats.past_due_minutes }} mins |

{% if past_due_tasks %}
## ⚠️ Past Due & High Priority
{% for task in past_due_tasks %}
- [ ] {{ task.task_text }} *(Due: {{ task.due_date }})* 🔗 [[{{ task.file_path | basename }}]]
{%- endfor %}
{% endif %}

## 📝 Open Tasks (By File)
{% for file_path, tasks in open_by_file.items() %}
### 📄 [[{{ file_path | basename }}]]
{% for task in tasks %}
- [ ] {{ task.task_text }}
{%- endfor %}
{% endfor %}

## ✅ Recently Completed (Last 7 Days)
{% for task in recently_completed %}
- [x] {{ task.task_text }} 🔗 [[{{ task.file_path | basename }}]]
{%- endfor %}
{% if not recently_completed %}
*No completions in the last 7 days.*
{% endif %}

## 📁 Source Files
{% for f in source_files %}
- [[{{ f | basename }}]]
{%- endfor %}
```

### Template Variables

| Variable | Type | Source |
|:---------|:-----|:-------|
| `project` | Project | `project` table |
| `stats` | object | Aggregated from `task` table |
| `past_due_tasks` | list[Task] | `task` table, `due_date < today`, `checked = 0` |
| `open_by_file` | dict[str, list[Task]] | `task` table grouped by `file_path` |
| `recently_completed` | list[Task] | `task` table, `act_comp_date >= today - 7 days`, `checked = 1` |
| `source_files` | list[str] | `file_project` join |

## 3. Super-Project Page

**Template:** `matlock/templates/super_project.md.j2`
**Output:** `_Matlock/Super Projects/<super_project_id>.md`
**Regenerated:** When any child project is updated.

### Template

```jinja
# 🌍 Super-Project: {{ super_project.title }}

## 📈 Child Project Status
| Project | Priority | Open Tasks | Completed | Due Date | Status |
| :--- | :--- | :--- | :--- | :--- | :--- |
{% for p in child_projects %}
| **[[{{ p.id }}]]** | {{ p.priority | title }} | {{ p.stats.open_count }} | {{ p.stats.completed_count }} | {{ p.due_date or "—" }} | {{ p.status_emoji }} {{ p.status_label }} |
{% endfor %}

## 🚨 Critical Aggregated Tasks
{% for task in critical_tasks %}
- [ ] [{{ task.project_title }}] {{ task.task_text }} 🔗 [[{{ task.file_path | basename }}]]
{%- endfor %}
{% if not critical_tasks %}
*No past-due tasks across child projects.*
{% endif %}
```

### Status Emoji Logic

| Condition | Emoji | Label |
|:----------|:------|:------|
| `past_due_count > 0` | 🔴 | At Risk |
| `open_count > 0` and no past-due | 🟡 | On Track |
| `open_count == 0` | 🟢 | Complete |

## 4. Daily History Page

**Template:** `matlock/templates/daily_history.md.j2`
**Output:** `_Matlock/History/<YYYY-MM-DD>.md`
**Regenerated:** Once after each `rollup` run (effectively immutable after the next day).

### Template

```jinja
# 📅 Daily History: {{ metric_date }}
**Day of Week:** {{ day_of_week }}

## 📈 Daily Totals
| Metric | Count | Minutes |
| :--- | :--- | :--- |
| **Tasks Completed** | {{ totals.tasks_completed_count }} | {{ totals.tasks_completed_minutes }} |
| **Tasks Created** | {{ totals.tasks_created_count }} | {{ totals.tasks_created_minutes }} |
| **Files Modified** | {{ totals.files_modified_count }} | — |

## 📊 Breakdown by Project
{% for row in project_rows %}
### {% if row.project %}[[{{ row.project.id }}]]{% else %}Unassigned{% endif %}
- Tasks Completed: {{ row.tasks_completed_count }} ({{ row.tasks_completed_minutes }} mins)
- End-of-Day Overdue: {{ row.tasks_past_due_count }}
{% endfor %}

## ⬅️ Navigation
* **Previous Day:** [{{ prev_date }}]({{ history_link(prev_date) }}) | **Back to Dashboard:** [Home]({{ dashboard_link }})
```

## Output Directory Structure

```
_Matlock/
    Home.md
    Due Today.md
    Past Due.md
    Due Soon.md
    Future Due.md
    Not Due.md
    Projects/
        backend_api.md
        frontend_ui.md
    Super Projects/
        website_overhaul.md
    History/
        2026/
            2026-04/
                2026-04-23.md
                2026-04-24.md
```

All files in `_Matlock/` are registered in the `file` table with `is_generated = 1` so the `sync` stage ignores them.
