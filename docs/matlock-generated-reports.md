# Matlock Generated Report Templates

**Version:** 0.2.x

This document specifies the Jinja2 Markdown dashboard types generated by the `report` stage. All output files are written to `output_directory` (`_Matlock/` by default) and render natively in Obsidian, VS Code, and GitHub without plugins.

Template files live at `matlock/templates/`.

---

## 1. Global Dashboard

**Template:** `matlock/templates/daily_dashboard.md.j2`
**Output:** `_Matlock/Home.md`
**Regenerated:** On every `matlock report` or `run-all` call; automatically by server mode after the nightly `rollup`.

### Template

```jinja
# 🎯 Matlock Daily Dashboard
**Date Generated:** {{ generated_at }}

- [⚠️ Warnings]({{ warnings_link }})
- [🌍 Super Projects]({{ super_projects_index_link }})
- [🚀 Projects]({{ projects_index_link }})

* **Current Streak:** {{ current_streak }} Days
* **Longest Streak:** {{ longest_streak }} Days{% if longest_streak_end %} (Ended: {{ longest_streak_end }}){% endif %}

## 🟩 Activity Heatmap (Last 5 Weeks)

| | W-4 | W-3 | W-2 | W-1 | Current |
|---|:---:|:---:|:---:|:---:|:---:|

## 🏆 Yesterday's Wins
*You completed **{{ yesterday_completed_count }} tasks**. View full details: [{{ yesterday_date }}]({{ history_link(yesterday_date) }})*
{% for project_id, count in yesterday_by_project.items() %}
- **[{{ project_id }}]({{ project_link(project_id) }})**: {{ count }} tasks completed
{%- endfor %}

### 📋 Tasks

|:-----|:-------:|:---------:|:------:|:----:|
```

### Template Variables

| Variable | Type | Source |
|:---------|:-----|:-------|
| `generated_at` | str (YYYY-MM-DD H:MM AM/PM) | Runtime |
| `warnings_link` | str | Relative path to `Warnings.md` |
| `super_projects_index_link` | str | Relative path to `Super Projects.md` |
| `projects_index_link` | str | Relative path to `Projects.md` |
| `current_streak` | int | Calculated from `daily_metric` |
| `longest_streak` | int | Calculated from `daily_metric` |
| `longest_streak_end` | str \| None | YYYY-MM-DD |
| `heatmap` | dict[str, list[str]] | Day-name → list of emoji per week (5 entries) |
| `yesterday_completed_count` | int | `daily_metric` |
| `yesterday_date` | str | YYYY-MM-DD |
| `yesterday_by_project` | dict[str, int] | `daily_metric` |
| `task_view_table_rows` | list[object] | Dashboard matrix rows grouped by due view and priority tier; populated cells link to page anchors (`#priority-high`, `#priority-medium`, `#priority-low`, `#priority-none`) |
| `active_super_project_rows` | list[object] | Super-projects that have at least one `In Progress` child project; each row has `super_project_label`, `super_project_link`, `current_streak`, `health`, `last_updated`, and per-due-category display strings |
| `recently_changed_files` | list[object] | Top changed non-generated files from `file` table (limited by `dashboard_recent_changes_limit`) |
| `source_link` | callable | `source_link(file_path)` → relative path to source file |
| `project_link` | callable | `project_link(project_id)` → relative path to `Projects/<id>.md` |
| `super_project_link` | callable | `super_project_link(sp_id)` → relative path to `Super Projects/<id>.md` |
| `history_link` | callable | `history_link(date_str)` → relative path to `History/<date>.md` |
| `due_today_link` | str | Relative path to `Due Today.md` |
| `past_due_link` | str | Relative path to `Past Due.md` |
| `due_soon_link` | str | Relative path to `Due Soon.md` |
| `future_due_link` | str | Relative path to `Future Due.md` |
| `not_due_link` | str | Relative path to `Not Due.md` |

## 2. Project Page

**Template:** `matlock/templates/project.md.j2`
**Output:** `_Matlock/Projects/<project_id>.md`
**Regenerated:** Per-project when affected files change (server mode) or on `matlock report`.

A virtual **`Projects/Unassigned.md`** is always generated alongside real project pages. It shows all tasks and files that are not mapped to any project.

### Template

```jinja
# 🚀 Project: {{ project.title }}

**Generated:** {{ generated_at }} | **Priority:** {{ project.priority | title }} | **Status:** {{ project.status or "—" }} | **Start Date:** {{ project.start_date or "—" }} | **Due Date:** {{ project.due_date or "—" }}
{% if project.super_project_id %}**Super-Project:** [{{ project.super_project_id }}]({{ super_project_link(project.super_project_id) }}){% endif %}

## 📊 Quick Stats
| Metric | Count | Estimated Effort |
| :--- | :--- | :--- |
| **Open Tasks** | {{ stats.open_count }} | {{ stats.open_minutes }} mins |
| **Completed** | {{ stats.completed_count }} | {{ stats.completed_minutes }} mins |
| **Past Due** | {{ stats.past_due_count }} | {{ stats.past_due_minutes }} mins |

{% if past_due_tasks %}
## ⚠️ Past Due & High Priority
{% for task in past_due_tasks %}
- ⬛ {{ task.task_text }} *(Due: {{ task.due_date }})* [↗]({{ source_link(task.file_path) }})
{% endfor %}
{% endif %}

## 📝 Open Tasks (By File)

{% for file_path, tasks in open_by_file.items() %}

### 📄 [{{ file_path | basename }}]({{ source_link(file_path) }})

{% for task in tasks %}
- ⬜ {{ task.task_text }}
{% endfor %}
{% endfor %}

## ✅ Recently Completed (Last 7 Days)

{% for task in recently_completed %}
- ✅ {{ task.task_text }} [↗]({{ source_link(task.file_path) }})
{% endfor %}
{% if not recently_completed %}
*No completions in the last 7 days.*
{% endif %}

## 📁 Source Files

{% for f in source_files %}
- [{{ f | basename }}]({{ source_link(f) }})
{% endfor %}
```

### Template Variables

| Variable | Type | Source |
|:---------|:-----|:-------|
| `project` | Project | `project` table (or virtual `SimpleNamespace` for Unassigned) |
| `generated_at` | str (YYYY-MM-DD H:MM AM/PM) | Runtime |
| `stats` | object | Aggregated from `task` table |
| `past_due_tasks` | list[Task] | `task` table, `due_date < today`, `checked = 0` |
| `open_by_file` | dict[str, list[Task]] | `task` table grouped by `file_path` |
| `recently_completed` | list[Task] | `task` table, `act_comp_date >= today - 7 days`, `checked = 1` |
| `source_files` | list[str] | `file_project` join |
| `source_link` | callable | `source_link(file_path)` → relative path to source file |
| `super_project_link` | callable | `super_project_link(sp_id)` → relative path to `Super Projects/<id>.md` |

## 3. Super-Project Page

**Template:** `matlock/templates/super_project.md.j2`
**Output:** `_Matlock/Super Projects/<super_project_id>.md`
**Regenerated:** When any child project is updated.

A virtual **`Super Projects/Unassigned.md`** is always generated alongside real super-project pages. It shows the same project-row table for projects that have no `super_project_id`.

### Template

```jinja
# 🌍 Super-Project: {{ super_project_display_title }}
**Generated:** {{ generated_at }} | [🏠 Back to Dashboard]({{ home_link() }})

## 🚀 Active Projects
{% if active_project_rows %}
| Project | Current Streak | Health | Last Updated | Due Today (count + est) | Past Due | Due Soon | Future Due | Not Due |
|:--------|:--------------:|:------:|:------------:|:-----------------------:|:--------:|:--------:|:----------:|:-------:|
{% for row in active_project_rows %}
| [{{ row.project_label }}]({{ row.project_link }}) | {{ row.current_streak }} | {{ row.health }} | {{ row.last_updated }} | {{ row.due_today_display }} | {{ row.past_due_display }} | {{ row.due_soon_display }} | {{ row.future_due_display }} | {{ row.not_due_display }} |
{% endfor %}
{% else %}
*No active projects.*
{% endif %}

## ⏸️ On-Hold Projects
{% if on_hold_project_rows %}
...
{% else %}
*No on-hold projects.*
{% endif %}

## ❌ Cancelled Projects
{% if cancelled_project_rows %}
...
{% else %}
*No cancelled projects.*
{% endif %}

## ✅ Completed Projects
{% if completed_project_rows %}
...
{% else %}
*No completed projects.*
{% endif %}
```

### Template Variables

| Variable | Type | Source |
|:---------|:-----|:-------|
| `super_project` | sqlite3.Row | `super_project` table row |
| `super_project_display_title` | str | `title` if set, otherwise `super_project_id` |
| `generated_at` | str (YYYY-MM-DD H:MM AM/PM) | Runtime |
| `active_project_rows` | list[object] | Child projects with `status = 'In Progress'`; each row has `project_label`, `project_link`, `current_streak`, `health`, `last_updated`, and per-due-category display strings |
| `on_hold_project_rows` | list[object] | Child projects with `status = 'On Hold'` |
| `cancelled_project_rows` | list[object] | Child projects with `status = 'Cancelled'` |
| `completed_project_rows` | list[object] | Child projects with `status = 'Complete'` |
| `home_link` | callable | `home_link()` → relative path to `Home.md` |
| `project_link` | callable | `project_link(pid)` → relative path to `Projects/<id>.md` |

### Health Emoji Logic

The `health` field on each project row is derived from live task data:

| Condition | Emoji |
|:----------|:------|
| `past_due_count > 0` | 🔴 |
| `due_today_count > 0` | 🟡 |
| otherwise | 🟢 |

## 4. Daily History Page

**Template:** `matlock/templates/daily_history.md.j2`
**Output:** `_Matlock/History/<YYYY-MM-DD>.md`
**Regenerated:** Once after each `rollup` run (effectively immutable after the next day). Can be accurately regenerated at any future date because `file_touch` and `daily_task` snapshot the events at rollup time.

### Template

```jinja
# 📅 Daily History: {{ metric_date }}

**Day of Week:** {{ day_of_week }} | **Generated:** {{ generated_at }} | [🏠 Home]({{ dashboard_link }}){% if prev_date %} | [⬅ {{ prev_date }}]({{ history_link(prev_date) }}){% endif %}{% if next_date %} | [{{ next_date }} ➡]({{ history_link(next_date) }}){% endif %}

---

## 📈 Daily Totals
| Metric | Count | Minutes |
| :--- | :--- | :--- |
| **Tasks Completed** | {{ totals.tasks_completed_count }} | {{ totals.tasks_completed_minutes }} |
| **Tasks Created** | {{ totals.tasks_created_count }} | {{ totals.tasks_created_minutes }} |
| **Files Modified** | {{ totals.files_modified_count }} | — |

## 🌍 Summary by Super-Project
{% if super_project_summary %}
| Super-Project | Created | Created (m) | Completed | Completed (m) |
...
{% endif %}

## 🚀 Summary by Project
{% if project_rows %}
| Project | Created | Created (m) | Completed | Completed (m) | Overdue (EoD) |
...
{% endif %}

## 📄 Files Touched
{% if file_touches %}
| File | Event | Time |
...
{% else %}
*No file-touch data available for this date.*
{% endif %}

## ✅ Tasks This Day
{% if task_list %}
| Task | Events | Estimate | Project |
...
{% else %}
*No task-event data available for this date.*
{% endif %}
```

### Template Variables

| Variable | Type | Source |
|:---|:---|:---|
| `metric_date` | str (YYYY-MM-DD) | `daily_metric.metric_date` |
| `day_of_week` | str | Derived from `metric_date` |
| `generated_at` | str (YYYY-MM-DD H:MM AM/PM) | `datetime.now()` at render time |
| `totals` | SimpleNamespace | Aggregated from all `daily_metric` rows for the date |
| `project_rows` | list[SimpleNamespace] | One row per project (plus Unassigned); includes `tasks_created_count/minutes`, `tasks_completed_count/minutes`, `tasks_past_due_count` |
| `super_project_summary` | list[SimpleNamespace] | Aggregated from `daily_metric` via `project → super_project`; includes Unassigned row; sorted with Unassigned last |
| `file_touches` | list[SimpleNamespace] | From `file_touch` table for the date; fields: `file_path`, `event_type`, `modified_text`, `source_link` |
| `task_list` | list[SimpleNamespace] | From `daily_task` table for the date (tasks with both `created` and `completed` events collapsed); fields: `task_text`, `events_display`, `estimate_display`, `source_link`, `project_title`, `project_link` |
| `prev_date` | str | Day before `metric_date` (always set; link only leads somewhere if that date has a history page) |
| `next_date` | str \| None | First `metric_date > metric_date` from `daily_metric`; None if this is the most recent history page |
| `project_link` | callable | `project_link(pid)` → relative path to `Projects/<pid>.md` |
| `history_link` | callable | `history_link(date_str)` → relative path to `History/<date>.md` |
| `dashboard_link` | str | Relative path to `Home.md` |

## Output Directory Structure

```
_Matlock/
    Home.md
    Due Today.md
    Past Due.md
    Due Soon.md
    Future Due.md
    Not Due.md
    Warnings.md
    Projects.md
    Super Projects.md
    Projects/
        backend_api.md
        frontend_ui.md
        Unassigned.md
    Super Projects/
        website_overhaul.md
        Unassigned.md
    History/
        2026/
            2026-04/
                2026-04-23.md
                2026-04-24.md
```

All files in `_Matlock/` are registered in the `file` table with `is_generated = 1` so the `sync` stage ignores them.
