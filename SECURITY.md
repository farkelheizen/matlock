# Security policy

## Reporting a vulnerability

Please report security vulnerabilities privately through
[GitHub's vulnerability reporting](https://github.com/farkelheizen/matlock/security/advisories/new).
Include the affected version, a description of the issue, and steps to
reproduce it. Do not include private vault contents or credentials.

Please do not disclose vulnerability details in a public issue before they
have been addressed.

## Protecting your data

Matlock indexes Markdown content and metadata. Treat vaults, configuration,
databases, audit results, and logs as potentially sensitive, and restrict
access accordingly. Security scanning and search policies are not guarantees
that all sensitive content will be identified or hidden.
